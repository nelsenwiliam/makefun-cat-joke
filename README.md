One-line cat joke for make.fun's "The One-Line Cat Joke That Lands" bounty: a single line, under 200 characters, with a setup and a turn that lands. The program writes the joke to `/output/entry.txt`.

The joke: "I got a second cat so the first one wouldn't be lonely. Now they ignore me as a team."

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
